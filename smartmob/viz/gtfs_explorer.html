GTFS의 구조와 버스 노선 설계

GTFS는 노선, 정류장, 운행일과 시간표를 서로 연결된 파일로 표현합니다. 하남시 실습 자료에서 각 파일의 관계를 확인한 뒤, 정류장과 시간표를 설정해 신규 노선의 GTFS를 작성합니다.

노선과 개별 운행의 관계

같은 노선이라도 출발시각이 다르면 별도의 운행(trip)으로 기록합니다. 각 운행의 정류장 방문 순서와 시각은 stop_times.txt에 저장합니다.

routes → route_id → trips → trip_id → stop_times → stop_id → stops
calendar → service_id → trips

운행별 정류장 시간표

정류장 이름을 선택하면 지도에서 위치를 확인할 수 있습니다. 이름이 같아도 stop_id가 다를 수 있으므로 식별자와 위치를 함께 확인합니다.

방문 순서정류장도착시각출발시각

정류장 위치와 방문 순서

실습 자료의 정류장 좌표를 방문 순서대로 연결했습니다. 연결선은 차량의 실제 주행 경로를 나타내지 않습니다. 녹색 선은 하남시 경계입니다. 지도를 드래그해 이동하고 스크롤로 확대·축소합니다.

같은 노선에서 출발시각이 다른 운행을 선택해 봅니다. route_id가 같아도 trip_id와 시간표는 달라집니다. 같은 노선에서 정류장 방문 순서가 같은 운행들은 하나의 패턴으로 묶습니다. 6장에서는 패턴별 시간표를 이용해 경로를 탐색합니다.
